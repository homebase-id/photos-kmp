## Auth-wave notes (006–008)

- **Logout shipped 2026-07-04** (delivery-fix/logout wave, no plan number): account
  button → confirm dialog → `YouAuthFlowManager.logout()` on both platforms; root
  gates flip automatically. Sim-smoked end-to-end incl. relaunch-stays-logged-out
  (credentials genuinely cleared). logout() also flips the outbox offline.

- Redirect scheme deliberately diverges from the chat-kmp pin: `homebase-photos://`
  (both mobile RedirectConfig actuals) so Chat and Photos never claim each other's
  redirects on one device.
- iOS needs NO Info.plist URL scheme: ASWebAuthenticationSession's
  `callbackURLScheme` intercepts the redirect (chat-kmp-proven pattern).
- Known stub left in place: `ApiCredentials.getIdentityId()` returns a hard-coded
  Uuid (`// TODO` upstream). Must be fixed in the real-repo/driveId-resolution
  wave — `PhotosRepositoryImpl.activeIdentity()` depends on it.
- Post-login next wave: resolve the Photos drive's local GUID (no ensureDrive
  helper exists; DriveSyncManager discovers granted drives) and swap
  `MockPhotosRepository` → `PhotosRepositoryImpl`.
